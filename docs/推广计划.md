# Smart Tenancy Pro — 自动化推广引擎 计划

## 核心规则

| 规则 | 值 |
|------|-----|
| 每人每月最多推广 | 1 次（30 天冷却） |
| 每天最多发送 | 5 人（可调） |
| 发送时间 | 每天上午 10:30 |
| 来源 | 数据 Sheet 里的 agent 电话 |

## 工作流（全自动）

```
数据抓取（每30分）
    │
    ▼
Google Sheet（Agent Name + Phone）
    │
    ▼
每日 10:30 ──→ 推广引擎启动
    │
    ├── 读取 Sheet 所有 agent 号码
    ├── 对比「推广记录」Sheet，排除 30 天内已发过的人
    ├── 按日期排序（越新越优先）
    ├── 取前 5 人（当天额度）
    ├── 逐个发 WhatsApp
    ├── 写入「推广记录」Sheet（姓名/电话/发送时间/状态）
    └── 结束
```

## 状态追踪（闭环）

| 状态 | 含义 | 怎么变 |
|------|------|--------|
| 已发 | 消息已送出 | 引擎自动标记 |
| 已回复 | agent 回了 WhatsApp | wa_listener 检测到同一号码回复 → 更新 |
| 已注册 | agent 填了 Form | form-process 检测邮箱/电话匹配 → 更新 |
| 已付费 | agent 付了 Stripe | stripe-check 检测 → 更新 |
